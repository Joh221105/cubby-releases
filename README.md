# Cubby releases

Downloads for [Cubby](https://github.com/Joh221105), a launcher for your own local-first apps. This repo holds only releases; there's no source code here.

## Install

Open the [latest release](https://github.com/Joh221105/cubby-releases/releases/latest) and download the file for your computer.

**Mac** (Apple silicon or Intel): download `Cubby-<version>-mac-universal.zip`, open it, and drag **Cubby** into your **Applications** folder before opening it. Cubby isn't signed by Apple yet, so the first time, right-click Cubby and choose **Open**.

**Windows**: download `Cubby-<version>-windows-x64-installer.exe` and run it. It installs for your account only, with no admin prompt. If SmartScreen warns you, choose **More info**, then **Run anyway**.

## Updates

Cubby checks for new versions on its own. When one is out, a note appears at the bottom of its sidebar. Every update is signed, and Cubby refuses any that isn't.
